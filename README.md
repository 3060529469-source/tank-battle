# 坦克大战 Battle City

一个用纯 HTML5 Canvas 实现的经典「坦克大战」网页小游戏，单文件即可运行，无需任何依赖。

## 玩法

- 控制己方坦克，守住右下方的基地（鹰）。
- 消灭每关全部敌人即可过关；基地被摧毁或生命耗尽则游戏结束。
- 砖墙可被子弹击毁，钢铁墙不可摧毁；河流坦克不能通过、但子弹可以飞过；树林会遮挡视野。

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动坦克 |
| 空格 / J | 开火 |
| Enter / 空格 | 开始 / 重新开始 |
| P | 暂停 |
| M | 静音 |

## 运行

直接用浏览器打开 `index.html` 即可：

```bash
open index.html
```

也可以使用任意静态服务器，例如：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 技术说明

- 纯 HTML + CSS + JavaScript，无外部依赖。
- 基于 Canvas 绘制，使用 `requestAnimationFrame` 游戏循环。
- 关卡地图以 13×13 字符数组定义，易于修改。
- 音效使用 Web Audio API 实时合成，无音频资源文件。
